# Simple ANN Racing

Первый MVP для обучения ИИ управлению машинкой на 2D-трассе: ручное вождение, препятствия, чекпоинты и запись демонстраций для imitation learning.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Стартовое меню содержит ровно два режима: **Sandbox** для создания и мгновенного тестирования карт и **Race**. В Race по умолчанию выбран игрок; на следующем экране можно выбрать обученную нейросеть, если существует `models/policy.npz`.

Чтобы сразу начать запись демонстраций игрока, используйте `python main.py --record`, затем выберите Race → Player.

Управление: `WASD` или стрелки, `R` / `К` (русская раскладка) — начать заезд заново, `Space` — поставить запись на паузу/продолжить, `Esc` — выйти.

Записи появляются в `data/demos/` в формате CSV. Одна строка — состояние и действие на одном кадре. В состояние входят 15 нормализованных лучей лидара, скорость, положение, время и прогресс; целевые действия — `steering`, `throttle`, `handbrake`.

`Shift` — ручник. Он снижает боковое сцепление, поэтому на скорости в повороте машинка входит в занос.

На экране отображаются время текущего круга, лучший круг и `score`. Для будущего обучения score рассчитывается как `10000 × завершённые круги + 1000 × чекпоинты − 10 × время в секундах`: агенту выгоднее быстро проходить чекпоинты и финишировать.

## Песочница и редактор карты

```bash
python main.py --mode sandbox --map maps/my-track.json
```

- ЛКМ + перетаскивание — создать препятствие; ПКМ — удалить препятствие.
- `C` / `С` — добавить чекпоинт под курсором; `X` / `Ч` — удалить последний.
- `S` / `Ы` — поставить старт под курсор; `F5` — сохранить JSON-карту.
- `Tab` — мгновенно переключиться в тестовый заезд. В нём работают обычные управление, занос и таймер; повторный `Tab` возвращает к редактору.
- Играть на сохранённой карте: `python main.py --mode race --driver player --map maps/my-track.json --record`.

## Автономное прохождение по вашим данным

1. Запишите несколько полных кругов в ручном режиме. Полезно добавить разные скорости, аккуратные повороты и несколько заносов.
2. Обучите модель на всех CSV из `data/demos/`:

```bash
python train.py --epochs 100
```

3. Запустите отдельный режим ИИ:

```bash
python main.py --mode race --driver ai --map maps/default.json
```

В автономном режиме сетка получает те же 15 лучей лидара и скорость, которые были записаны при ручной езде, и сама выбирает руль, газ и ручник. В HUD отображается `mode: AI`, время круга, лучший круг и score. Сначала тестируйте на карте, на которой записывались данные; после этого собирайте корректирующие заезды на новых трассах и переобучайте модель.

## Структура логов

Логи ручного игрока раскладываются по папкам `data/demos/race/<track_id>/`. В каждом CSV есть `run_id`, `mode`, `driver`, `track_id`, `map_path`, номер эпизода и время круга. `track_id` включает короткий хеш содержимого: если карту отредактировать и сохранить с тем же именем, её примеры попадут в отдельную группу. `train.py` читает все эти группы рекурсивно; позже можно обучать на выбранной трассе, отфильтровав CSV по `track_id`.

## Следующий этап
