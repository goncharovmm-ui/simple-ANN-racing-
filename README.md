# Simple ANN Racing

Первый MVP для обучения ИИ управлению машинкой на 2D-трассе: ручное вождение, препятствия, чекпоинты и запись демонстраций для imitation learning.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```

Стартовое меню содержит **Sandbox**, **Race** и **Training center**. В Race по умолчанию выбран игрок; стрелками можно выбрать любую сохранённую `.npz`-модель из `models/` (включая веса каждой эпохи), а затем запустить её на выбранной карте. Третья кнопка Race открывает **Replay: neural signals**.

В каждом заезде игрока запись начинается автоматически. До прохождения полного круга она находится во временной папке; после первого завершённого круга файл переносится в датасет. Незавершённый заезд, включая Game Over, удаляется.

Управление: `WASD` или стрелки, `Shift` — ручник/занос, `R` / `К` (русская раскладка) — начать заезд заново, `Esc` — выйти. Удар о стену снижает скорость и отбрасывает машинку; пятый удар завершает попытку. Попытка также считается неудачной, если машинка движется медленнее 12 единиц/с в течение пяти секунд.

Записи появляются в `data/demos/` в формате CSV. Одна строка — состояние и действие на одном кадре. В состояние входят 15 нормализованных лучей лидара, скорость, положение, время и прогресс; целевые действия — `steering`, `throttle`, `handbrake`.

`Shift` — ручник. Он снижает боковое сцепление, поэтому на скорости в повороте машинка входит в занос.

На экране отображаются время текущего круга, лучший круг и `score`. Для обучения score рассчитывается как `10000 × завершённые круги + 2500 × чекпоинты + направленный прогресс − 10 × время в секундах − 250 × столкновения`. Направленный прогресс положителен при движении по часовой стрелке и штрафуется сильнее при движении назад; срезать можно, но полный маршрут с чекпоинтами выгоднее.

## Песочница и редактор карты

```bash
python main.py --mode sandbox --map maps/my-track.json
```

- ЛКМ + перетаскивание — создать препятствие; ПКМ — удалить препятствие.
- `C` / `С` — добавить чекпоинт под курсором; `X` / `Ч` — удалить последний.
- Вверху экрана есть кнопки: **Add obstacle**, **Add checkpoint**, **Set start**, **Set finish**, **Delete**, **Save map** и **Test track**. Выберите кнопку, затем щёлкните по карте. В режиме **Move** перетаскивайте существующие объекты мышью. Старт — это центр случайной стартовой зоны; финиш — отдельная зелёная точка, которую можно двигать.
- В Test track работают обычные управление, занос, таймер и лимит из пяти столкновений; зоны чекпоинтов показаны кольцами. Попадание в центр даёт больше очков, чем попадание у края зоны; `Esc` возвращает в песочницу.
- Играть на сохранённой карте: `python main.py --mode race --driver player --map maps/my-track.json`.

## Автономное прохождение по вашим данным

1. Запишите несколько полных кругов в ручном режиме. Полезно добавить разные скорости, аккуратные повороты и несколько заносов.
2. Обучите модель на всех CSV из `data/demos/`:

```bash
python train.py --epochs 100
```

Архитектуру можно выбрать при запуске обучения. Одно число повторяется для всех скрытых слоёв, а список задаёт ширину каждого слоя:

```bash
python train.py --epochs 100 --hidden-layers 3 --hidden-units 128,64,32
```

Старые `.npz` с одной скрытой прослойкой загружаются без изменений. Новые модели сохраняют архитектуру внутри файла и могут содержать любое число скрытых слоёв.

3. Запустите отдельный режим ИИ:

```bash
python main.py --mode race --driver ai --map maps/default.json
```

В автономном режиме сетка получает те же 15 лучей лидара и скорость, которые были записаны при ручной езде, и сама выбирает руль, газ и ручник. В HUD отображается `mode: AI`, время круга, лучший круг и score. Сначала тестируйте на карте, на которой записывались данные; после этого собирайте корректирующие заезды на новых трассах и переобучайте модель.

## Центр обучения

Запустите `python main.py` и выберите **Training center**. Центр обучения:

1. Находит лучший завершённый человеческий круг для выбранной карты.
2. Передаёт его как начальный экспертный датасет, а затем запускает 10 эпох DAgger с 20 машинами и отдельной автономной проверкой.
3. Показывает прогресс, прошедшее время и примерный остаток по предыдущим запускам.
4. После завершения автоматически собирает пятиминутное видео и сохраняет его в `~/Desktop/simple-ann-<run>.mp4`.

Кнопки `M` и `L` переключают карту и базовую модель. В полях сверху можно задать имя карты и модели. Параметры по умолчанию: 10 эпох, 3 лучшие человеческие траектории и 7 машин на каждую (21 машина сбора на эпоху). `T` начинает обучение, `S` сохраняет выбранную/лучшую модель на рабочий стол, `V` пересобирает видео, `Enter` открывает его. Числовые поля редактируются кликом по числу и вводом с клавиатуры; кнопки `-` и `+` находятся слева и справа от каждого числа. Это позволяет менять число эпох, лучших траекторий, машин на траекторию, скрытых слоёв, выбранный слой и нейронов выбранного слоя. После каждой эпохи в интерфейсе показывается её фактическое время; ETA берётся из прошлых запусков.

Чекпоинты независимы: их можно проходить в любом порядке, каждый засчитывается один раз, а точность попадания масштабирует бонус. В обучающих заездах финиш засчитывается только после всех чекпоинтов, чтобы сеть училась проходить полный круг. Если выбрать другую карту и существующую модель, она дообучается на новых лучших человеческих кругах, а результат сохраняется отдельным именованным файлом.

Каждая эпоха сохраняет отдельные веса `models/cycle/<run-name>/policy_001.npz`, `policy_002.npz` и т.д., а лучшая версия — `best.npz`. В режиме Replay выбранная сеть прогоняется по каждому кадру записи: на экране видны машина, лидар, steering, throttle, ручник и скорость. `Space` — пауза, `↑/↓` — скорость повтора, `+/-` — ограничение FPS, `←/→` — покадровый просмотр, `N/P` — другая запись, `R` — перезапуск.

То же самое можно запускать без интерфейса:

```bash
python run_training_cycle.py --epochs 10 --agents 20 --eval-agents 20 --seed-data data/demos/race/<best.csv> --base-model models/policy.npz --run-name my-track-v1 --output artifacts/training-history-my-track-v1.json
```

Для DAgger с двумя скрытыми слоями, например, добавьте `--hidden-layers 2 --hidden-units 64,32`.

Запуск повтора из командной строки:

```bash
python main.py --mode replay --model models/cycle/my-track-v1/policy_005.npz --map maps/my-track.json --replay-data data/demos/race/my-track-<hash>/player.csv
```

Для анализа внутренней работы сети можно построить десятикадровый монтаж и отчёт абляции:

```bash
python analyze_neural_model.py --model /path/to/model.npz --map maps/default.json \
  --output artifacts/neural-analysis.png --report artifacts/neural-analysis.json \
  --pruned-model artifacts/neural-analysis-pruned.npz \
  --animation artifacts/neural-analysis-toggle.mp4
```

Монтаж показывает карту, машину, 16 входов, 64 скрытых нейрона, 3 выхода и цветом подсвеченные вклады связей. В JSON `effective_at_5_percent` указано, сколько скрытых нейронов дали не менее 5% от максимального изменения выхода при отключении одного нейрона.
Скрипт автоматически сохраняет сокращённую сеть: скрытые нейроны с влиянием ниже 5% от максимального убираются, а в JSON записывается сравнение выходных сигналов полной и сокращённой версий. MP4 — это покадровая анимация: на каждом кадре показан один момент записи, затем для того же момента переключается `FULL`/`PRUNED`.
Прозрачность связей и узлов зависит от силы сигнала: слабые вклады почти невидимы, сильные остаются яркими.

## DAgger с искусственным экспертом

Лучший чистый человеческий заезд нужно использовать для начальной модели, а не смешивать с неудачными попытками:

```bash
python train.py --data data/demos/race/default-14c26c7f4561/player_20260928T134838Z_146c954b.csv --epochs 100
```

После этого запустите DAgger. Сеть управляет машинкой, а встроенный искусственный эксперт сохраняет корректные действия в опасных или сильно отличающихся от эталона состояниях:

```bash
python main.py --dagger models/policy.npz --agents 20 --speed 8
```

20 машин запускаются одновременно с разными случайными стартами. `--speed 8` выполняет восемь физических шагов на один экранный кадр, а каждая экспертная метка сразу сбрасывается в CSV. На карте остаются траектории: чем зеленее линия, тем лучше завершённый заезд; красные линии означают неудачные или повреждённые попытки. Корректировки сохраняются отдельно в `data/demos/dagger/<track_id>/` и не смешиваются с ручными примерами.

После пакета переобучите модель на всех CSV:

```bash
python train.py --epochs 100
```

Затем снова запустите пакет DAgger. Одна итерация — это **20 заездов → обучение → сравнение числа финишей, времени и ударов**.

### Проверка сложности сети и простого правила

Чтобы сравнить архитектуры на одной трассе, можно запустить небольшой sweep:

```bash
python sweep_architectures.py --data data/demos/race/default-0a1d39705e91 \
  --epochs 25 --batch-size 1024 --output artifacts/architecture-sweep-current.json
```

Для проверки гипотезы «если слева луч короче, рулить вправо» используется интерпретируемый lidar-baseline без нейронной сети:

```bash
python analyze_rule_baseline.py --data data/demos --driver player \
  --output artifacts/rule-baseline-player.json
```

Скрипт считает корреляции, ошибку правила и сравнивает её с постоянным рулём и линейной моделью. Прямой прогон правила и сети на трассе выполняется через `evaluate_controllers.py`.

Для регрессионной проверки направленного счёта:

```bash
python -m unittest discover -s tests -v
```

### Полный headless-цикл и видео

Для двадцати эпох по двадцать параллельных машин, без окон во время расчёта:

```bash
python run_training_cycle.py --epochs 20 --agents 20 --run-name route-expert --output artifacts/training-history-route-expert.json
```

В каждой эпохе эксперт ведёт только часть машин: его доля плавно снижается с 85% до 10%, поэтому сеть постепенно берёт управление на себя, но получает примеры выхода из ошибок. Машины стартуют на случайных сегментах трассы. После обучения новая модель проходит отдельную полностью автономную оценку из 20 машин; только модель с лучшим числом финишей и средним временем становится следующей базовой моделью. Скрипт сохраняет отдельные DAgger-данные и модели по имени запуска, а также записывает историю. Затем создайте пятиминутный ролик:

```bash
python make_training_movie.py --history artifacts/training-history-route-expert.json --output artifacts/training-progress-route-expert.mp4 --duration 300
```

## Структура логов

Логи ручного игрока раскладываются по папкам `data/demos/race/<track_id>/`. В каждом CSV есть `run_id`, `mode`, `driver`, `track_id`, `map_path`, номер эпизода, число столкновений и время круга. `track_id` включает короткий хеш содержимого: если карту отредактировать и сохранить с тем же именем, её примеры попадут в отдельную группу. `train.py` читает все эти группы рекурсивно; позже можно обучать на выбранной трассе, отфильтровав CSV по `track_id`.
