# Simple ANN Racing

Первый MVP для обучения ИИ управлению машинкой на 2D-трассе: ручное вождение, препятствия, чекпоинты и запись демонстраций для imitation learning.

## Запуск

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py --record
```

Управление: `WASD` или стрелки, `R` — начать заезд заново, `Space` — поставить запись на паузу/продолжить, `Esc` — выйти.

Записи появляются в `data/demos/` в формате CSV. Одна строка — состояние и действие на одном кадре. В состояние входят 15 нормализованных лучей лидара, скорость, положение и прогресс; целевые действия — `steering` и `throttle`.

## Следующий этап

Обучить небольшую PyTorch-модель предсказывать `steering` и `throttle` по лидару, скорости и направлению к следующему чекпоинту. Затем оценивать её на отложенных трассах и собирать корректирующие демонстрации (DAgger).
